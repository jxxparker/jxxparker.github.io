HoopVortex: Snake Draft Showdown

HoopVortex is a free, browser-based multiplayer NBA draft game. Friends join a room by link, take turns drafting all-time NBA players in snake order under a server-enforced pick timer, and a deterministic simulation decides whose five wins. Built with React, TypeScript, and Supabase (Postgres + Realtime, with draft rules enforced server-side through RPC functions and Row Level Security), deployed to Cloudflare Pages via GitLab CI/CD on a stack targeting $0/month.
